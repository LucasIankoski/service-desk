# Issue tracker

O projeto usa GitHub Issues e Pull Requests em `LucasIankoski/service-desk`.

1. Procure referências `#<número>` nos commits e no título da branch.
2. Consulte com `gh issue view <número>` ou `gh pr view <número>` quando autenticado.
3. Sem issue, use `docs/specs/service-desk-v1.md` como especificação de origem.
4. O ponto de referência padrão para revisão é `main`.
